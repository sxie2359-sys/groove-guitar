# Groove Guitar

面向吉他日常练习的本地浏览器节拍器与鼓机原型。无需账号或后端，打击音由浏览器 Web Audio 合成，中文女声数拍使用随应用附带的短语音文件，播放时无需联网。

## 使用

直接用现代浏览器打开 `index.html`。如果浏览器限制本地文件的音频模块，请在本目录启动一个静态文件服务器后访问。点击“开始练习”以启用音频。

## 已包含

- 40–220 BPM 节拍器、拍号、细分、Swing 与点按测速
- BPM 上方每拍可单独开关提示音；静音拍仍正常计时并显示播放进度
- 鼓机步数会随 2/4–7/8 拍号自动调整，切换拍号时保留并延展当前鼓点
- 节拍音、人声和鼓机提供独立音量控制
- “明亮女声 · 中文数拍”：普通话女声按主拍报数，支持一至七；女声音频经过静音裁切、音量统一和清晰度调整，高速时自动缩短以避免叠字
- 底鼓、军鼓、踩镲 16 步音序器和三个律动预设
- 每累计练习两分钟增加 5 BPM 的渐进提速计划；暂停节拍器时训练计时也会暂停
- Space 开始 / 停止，T 点按测速
- BPM、拍号、细分、Swing、提示音设置和鼓点保存在本机浏览器
- 损坏或不完整的本地设置会自动恢复为安全默认值
- 节拍器与鼓机分开控制；开始鼓机时会先关闭节拍器，之后仍可单独打开节拍器叠加
- 点亮一个鼓机格子时会试听对应音色
- 和弦知识库包含 14 种风格模块，涵盖日系摇滚、英伦摇滚 / Britpop（含 Oasis 参考）、City Pop、经典摇滚、布鲁斯、流行摇滚、爵士、Bossa Nova、Funk、灵魂乐 / R&B、民谣、乡村、朋克 / 另类摇滚与金属 / 硬核
- 各模块提供多组和弦进行和可点选的和弦图；每个和弦可切换开放把位及 4–7、8–10、10–12 品的可用指型，所选按弦位置会显示在 50s 单切风格吉他指板
- 风格练习内容参考 Open Music Theory 与 Berklee Online 等乐理和吉他教学资料；页面中的和弦进行作为教学练习模板，不代表特定歌曲的逐段扒谱

## 结构

- `src/audio-engine.js`：Web Audio 合成和预读调度，不依赖 UI
- `assets/count-zh-female/`：普通话女声数字音频与来源说明
- `src/app.js`：界面事件、状态持久化和应用逻辑
- `src/chord-library.js`：风格和弦数据、和弦图、标准调弦指板视图
- `src/chord-library.css`：知识库页面和指板样式
- `styles.css`：响应式视觉样式
- `index.html`：页面骨架

新增声音请扩展 `AudioEngine.playDrum`；新增训练模块可单独放入 `src/`，再从 `app.js` 连接状态与界面。

## GitHub 参考

本原型的功能和结构参考了 MIT 许可的 [pierrehanne/metronome](https://github.com/pierrehanne/metronome)（节拍器调度与拍号、细分）和 [biggyspender/web-audio-drum-machine](https://github.com/biggyspender/web-audio-drum-machine)（鼓机音序器）。本目录没有复制其源代码或音频素材。
